# FlowPilot AI — Architecture Specification

## 1. Executive Summary

**FlowPilot AI** is an autonomous business operations platform designed to convert complex operational problems into executable, trackable, and independently verified workflows.

Traditional enterprise business operations suffer from high coordination overhead: employees switch between ERP, warehouse management, and carrier portals, manually inspecting discrepancies, coordinating departments, obtaining approvals, and checking whether corrective actions worked.

FlowPilot AI bridges this gap with a governed operational lifecycle:
```
DETECT → INVESTIGATE → PLAN → VALIDATE → APPROVE → EXECUTE → VERIFY → RECOVER OR COMPLETE
```

### Coordinator Agent
Tracks state machine transitions: `DRAFT`, `QUEUED`, `INVESTIGATING`, `PLANNING`, `VALIDATING`, `AWAITING_APPROVAL`, `EXECUTING`, `VERIFYING`, `RECOVERING`, `COMPLETED`, `PARTIALLY_COMPLETED`, `FAILED`, `CANCELLED`.

### Investigation Agent
Gathers operational evidence from database records:
- Identifies orders past expected delivery dates.
- Compares required order quantities with available warehouse stock and reorder thresholds.
- Identifies carrier dispatch delays and transit exceptions.

### Planning Agent
Uses Google Gemini 2.5 Flash (or deterministic fallback in Demo Mode) to generate structured output conforming to the validated Zod schema:
- Categorizes root causes (Inventory shortage, carrier exception, dispatch hold).
- Proposes prioritized corrective actions with explicit risk ratings and approval requirements.

### Execution Service
Executes permitted tools with strict allowlists and argument validation. Guarantees that arbitrary code or SQL generated by models is never executed.

### Verification Service
Independently queries the relational database after tool execution to prove the expected side effects were achieved (e.g., verifying that a RestockRequest record exists with the exact product and batch quantity).

### Recovery Service
Classifies errors as transient (e.g., timeouts, 503/504 gateways, lock contention) versus permanent. Transient errors are retried with exponential backoff and idempotency keys up to a configured threshold.

## 3. Technology Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, React Router 7, Lucide React, Recharts.
- **Backend**: Node.js, Express, TypeScript, Zod, bcryptjs, JSON Web Tokens (JWT).
- **Database & ORM**: Prisma ORM with SQLite (persistent, zero-dependency local development; PostgreSQL compatible).
- **AI Integration**: Google Gemini API via official `@google/genai` SDK + deterministic rule-based demo engine.
